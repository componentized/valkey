# tcp-connector-constants

The keys of the `tcp-connector` config and their defaults, as constants.

Exports `componentized:valkey/tcp-connector-constants`, for the [`tcp-connector`](../tcp-connector/) and the components that derive their config from it, like [`internal-tcp-connector-lookup-config`](../internal-tcp-connector-lookup-config/) and [`internal-tcp-connector-egress-config`](../internal-tcp-connector-egress-config/).

Generated by [constants](https://github.com/componentized/constants) from the `@value` of each function in [`tcp-connector-constants.wit`](../../wit/tcp-connector-constants.wit).
